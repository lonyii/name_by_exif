# Name by Exif

> 按 EXIF 拍摄时间批量重命名照片与视频，并清理重复文件。

一个只依赖 `cmd.exe` + `exiftool.exe` 的 Windows 批处理小工具。

Rename pics & movs by EXIF `DateTimeOriginal` / `CreateDate`, then delete duplicate files.

| 项目 | 内容 |
| --- | --- |
| 脚本 | `!NamebyExif_v15.11.22.22.bat` |
| 版本 | v15.11.22（build 22），最后构建 2015-11-22 |

## ⚠️ 使用前必读

**这个脚本会永久删除文件。** 它用 `del /q /f` 直接删除判定为重复的文件，**不经过回收站**。脚本生成的「恢复脚本」只是把判定为重复而保留下来的那份，复制成被删文件的名字，并不是把被删文件的原始数据找回来。

第一次使用请务必：

1. 完整备份要整理的目录；
2. 在**副本**上试跑一次，检查重命名与删除结果；
3. 确认无误后再对原始目录使用。

---

## 它能做什么

1. 读取照片的 EXIF `DateTimeOriginal`、视频的 `CreateDate`，把文件重命名为 `<日期时间>_<序号>.<原扩展名>`。
2. 没有拍摄时间时，退回使用**文件修改时间**；视频时间按 UTC → UTC+8 修正（写死 +28800 秒）。
3. 同一秒有多个文件时，用 `_1`、`_2`… 递增序号避免覆盖。
4. 重命名完成后做重复文件比对：媒体文件按文件大小 + 可配置的 EXIF 标签；其它文件按大小 / 修改时间 / 文件名。
5. 删除重复文件，并生成一份可执行的「恢复脚本」与比对记录。
6. **可重复运行**：文件名已符合命名格式的文件会被跳过。

## 快速开始

**关键前提**：脚本内部用相对路径 `exiftool.exe` 调用工具，且运行时会 `cd /d` 切到待整理目录，因此 `exiftool.exe` 必须位于**待整理目录**中，或已加入系统 `PATH`。只把两个文件放在工具目录、却去整理另一个文件夹，会读不到 EXIF 并可能把文件改成 `_1.jpg` 这类错误名字。

1. 把 `!NamebyExif_v15.11.22.22.bat` 和 `exiftool.exe` **一起复制进要整理的文件夹**。
2. 双击 `.bat`（窗口会被脚本改成 80×5 的蓝色小窗，属正常现象）。
3. 按提示把该文件夹**拖入窗口**后回车；也可直接粘贴完整路径。
4. 若目录里混有非媒体文件，会出现 `1、只处理媒体文件[默认] / 2、处理所有文件`，按需输入 1 或 2。
5. 等待重命名与去重完成。若有删除，会弹出记事本显示比对记录——**关闭记事本后脚本才继续**。
6. 最后显示 `整理完毕，重命名文件 X 项，删除重複文件 Y 项！`，约 5 秒后自动退出。

命令行传参也可以（路径含空格请加引号）：

```bat
"!NamebyExif_v15.11.22.22.bat" "D:\照片\2015"
```

其它部署方式（把工具目录加入 `PATH`、改成绝对路径）见 [使用说明.md](使用说明.md) §2。

## 命名结果示例

| 原名 | 重命名后 | 时间来源 |
| --- | --- | --- |
| `IMG_1234.JPG` | `2015-11-22_143025_1.JPG` | EXIF `DateTimeOriginal` |
| `IMG_1235.JPG` | `2015-11-22_143025_2.JPG` | 同一秒的第二个文件 |
| `MVI_0001.MOV` | `2015-08-01_180000_1.MOV` | `CreateDate`（UTC 10:00 + 8 小时） |
| `scan.png` | `2016-06-29_104500_1.PNG` | 无 EXIF，改用文件修改时间 |

默认格式 `%%Y-%%R-%%d_%%H%%M%%S`，其中 `%%R` 是作者自定义的「月」占位符（脚本内部转成 exiftool 的 `%m`），`%%d` 为日、`%%Y` 为年、`%%H%%M%%S` 为时分秒。**格式中不支持空格和 `. < > / ? | \` 等特殊字符。**

## 配置项速查

全部位于脚本头部，改完请用 **GBK / ANSI 编码**保存：

| 变量 | 默认值 | 作用 |
| --- | --- | --- |
| `exiftool` | `exiftool.exe` | 依赖工具的路径 |
| `compare_level_media` | `0` | 媒体去重等级 0~5；0 = 只比文件大小 |
| `advance_compare_Parameter` | `$Flash $ImageSize $Software $GPSPosition $BrightnessValue` | 等级 1~5 依次比对的 EXIF 标签 |
| `compare_level_other` | `2` | 其它文件去重等级 1~3：大小 > 修改时间 > 文件名 |
| `date_format` | `%%Y-%%R-%%d_%%H%%M%%S` | 命名格式 |
| `bool_dir_current` | `1` | 是否递归子目录（0 = 否） |
| `Supporting_format_photo` | `.jpg$ .png$ .nef$ .psd$` | 图片扩展名（findstr 正则） |
| `Supporting_format_movie` | `.mov$ .mp4$ .avi$` | 视频扩展名 |

完整说明与修改示例见 [使用说明.md](使用说明.md) §8。

## 已知限制

- **会永久删除文件**，去重关闭开关在脚本中不存在；只想重命名请自行备份后改造脚本。
- 随包 `exiftool.exe` 是 9.34（2013 年前后），对 HEIC、WebP、新型相机 RAW 等支持有限；读不到 EXIF 时一律退回文件修改时间，结果可能不是拍摄时间。
- 视频时区修正固定为 UTC+8，其它时区需自行修改脚本中的 `28800`。
- 文件修改时间会随复制 / 传输 / 编辑改变，不能当作可靠的拍摄时间。
- 去重只在**时间戳前缀相同**的文件之间进行，不同时刻的相同内容不会被判为重复。
- 脚本会 `start /wait notepad` 阻塞，关闭记事本后才继续；运行日志随后会被删除，需要留档请在记事本里另存为。
